## Выявленные проблемы

### Проблема 1: Разрешение username не применяется к существующим каналам

**Причина:** В коде `subscribe_to_theme` разрешение username через Telegram вызывается, но обновление `tg_channel_id` для существующих каналов не выполняется, если канал уже найден по `username`.

**Решение:** Обновить логику, чтобы обновлять `tg_channel_id` и `title` для существующих каналов, если они получены из Telegram.

### Проблема 2: Посты не парсятся (messages_processed: 0)

**Возможные причины:**
1. Каналы не публикуют посты часто (за последние 24 часа нет новых постов)
2. Каналы недоступны (приватные, удалены, заблокированы)
3. Проблемы с доступом Telegram клиента к каналам
4. Таймауты при парсинге больших каналов

**Решение:** 
- Проверить доступность каналов вручную
- Увеличить `historical_hours` для новых каналов
- Проверить логи на ошибки доступа

## Рекомендации

1. **Исправить обновление tg_channel_id для существующих каналов** - применить разрешение username даже если канал уже существует
2. **Проверить доступность каналов** - убедиться, что каналы публичные и доступны
3. **Увеличить период парсинга для новых каналов** - парсить больше чем 24 часа истории
4. **Мониторинг парсинга** - отслеживать, почему `messages_processed: 0`
