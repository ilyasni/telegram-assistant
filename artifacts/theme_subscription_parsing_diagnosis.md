## Выявленные проблемы и исправления

### ✅ Проблема 1: Разрешение username не работало

**Причина:** Использовались неправильные атрибуты `settings.master_api_id` вместо получения из переменных окружения.

**Исправление:** Обновлен код для получения API credentials из переменных окружения (`MASTER_API_ID` или `TELEGRAM_API_ID`).

**Результат:** Разрешение username теперь работает корректно.

### ✅ Проблема 2: Обновление tg_channel_id для существующих каналов

**Причина:** Код обновлял `tg_channel_id` только при поиске по `tg_channel_id`, но не при поиске по `username`.

**Исправление:** Добавлено обновление `tg_channel_id` и `title` для существующих каналов, найденных по `username`.

**Результат:** При следующей подписке на тему существующие каналы будут обновлены с `tg_channel_id` из Telegram.

### ⚠️ Проблема 3: Посты не парсятся (messages_processed: 0)

**Причина:** 
- Historical mode парсит только последние 24 часа
- Если канал не публиковал посты за последние 24 часа, постов не будет найдено
- Это нормальное поведение для новых каналов или неактивных каналов

**Решение:** 
- Для новых каналов можно увеличить `historical_hours` в конфигурации парсера
- Или дождаться следующего цикла парсинга (incremental mode будет парсить новые посты)
