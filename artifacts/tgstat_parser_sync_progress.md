## Исправления

### 1. Проблема с Brotli кодировкой
**Проблема**: Ответ от TGStat приходил с `Content-Encoding: br` (Brotli), но библиотека `brotli` не была установлена, поэтому HTML не распаковывался.

**Решение**: Убрал `br` из `Accept-Encoding`, оставил только `gzip, deflate`, которые поддерживаются стандартной библиотекой Python.

**Результат**: HTML теперь распаковывается правильно, парсер находит 369 тем.

### 2. Улучшенная обработка ошибок Selenium
**Проблема**: При ошибках Selenium парсер не переключался на fallback.

**Решение**: Добавил try/except блоки для обработки ошибок браузера и автоматического переключения на requests fallback.

### 3. Исправлена дедупликация элементов
**Проблема**: Дедупликация выполнялась только для fallback, но не для элементов из селекторов.

**Решение**: Дедупликация теперь выполняется для всех элементов, независимо от источника.

## Мониторинг

Синхронизация выполняется в фоне. Для проверки прогресса:

```bash
# Проверить статистику
docker compose exec -T supabase-db psql -U postgres -d postgres -c "
SELECT 
    COUNT(*) FILTER (WHERE channels_count = 0) as themes_with_0_channels,
    COUNT(*) FILTER (WHERE channels_count > 0) as themes_with_channels
FROM (
    SELECT t.id, COUNT(tc.theme_id) as channels_count
    FROM themes t
    LEFT JOIN theme_channels tc ON t.id = tc.theme_id
    GROUP BY t.id
) subq;
"

# Проверить логи
docker compose logs --tail=100 --since=5m tgstat-parser | grep -E "(Sync progress|Theme saved|channels_count)"
```
