## Рекомендации по реализации

### UI изменения (приоритет 1)

Рекомендуется начать с обновления `webapp/js/channels.js`:
1. Добавить параметр `source` в запрос `loadChannels()`
2. Разделить каналы на два массива: `manualChannels` и `themeChannels`
3. Обновить `renderChannels()` для отображения двух секций
4. Добавить бейджи и подсказки

### Интеграция синхронизации (приоритет 2)

Рекомендуется **Вариант C** (фоновая задача):
1. Добавить поле `updated_at` в `theme_channels` (если еще нет)
2. Создать фоновую задачу, проверяющую изменения
3. При обнаружении изменений → вызвать `ThemeSyncService.sync_theme_subscriptions()`

Альтернатива: добавить вызов синхронизации в `sync_theme_channels()` после коммита изменений.
