# Фильтрация подборок по количеству каналов

**Дата**: 2026-01-13  
**Задача**: Показывать пользователям только подборки с количеством каналов > 1

## Реализация

### Изменения

**Файл**: `api/services/tgstat_service.py`
**Метод**: `get_all_themes()`

Добавлен фильтр `WHERE channels_count > 1` во все SQL запросы:
- Базовый запрос списка подборок
- Запрос с поиском
- Запросы для подсчета общего количества (для пагинации)

### Результат

**До фильтрации**:
- Всего подборок: 80
- Подборок с > 1 канала: 79
- Подборок с ≤ 1 канала: 1

**После фильтрации**:
- Пользователям показываются только 79 подборок с > 1 канала
- Подборки с 0 или 1 каналом скрыты

## Влияние

### API Endpoints
- ✅ `GET /api/themes` - фильтрует автоматически
- ✅ `GET /api/themes?search=...` - фильтрует автоматически

### Bot Commands
- ✅ `/themes` - использует API, фильтрация работает автоматически
- ✅ `/my_themes` - показывает только подключенные подборки (не затрагивается)

### Web UI
- ✅ `webapp/js/themes.js` - использует API, фильтрация работает автоматически

## Проверка

```bash
# Проверить через API
curl http://localhost:8000/api/themes?limit=10

# Проверить через бота
/themes
```

## Примечания

- Фильтрация происходит на уровне БД, что эффективно
- Подборки с 0 или 1 каналом не удаляются, просто не показываются пользователям
- Администраторы могут видеть все подборки через прямой доступ к БД
