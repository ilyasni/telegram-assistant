## Проблема с браузером

Браузер падает во время длительной работы:
```
ConnectionRefusedError: [Errno 111] Connection refused
HTTPConnectionPool(host='localhost', port=XXXXX): Max retries exceeded
```

Это происходит потому, что:
1. ChromeDriver сессия закрывается после длительной работы
2. Браузер не пересоздается автоматически при таких ошибках
3. Нужно улучшить обработку ошибок для автоматического пересоздания браузера

## Решение

Улучшить обработку ошибок в `selenium_browser.py`:
- При ошибке `Connection refused` пересоздавать браузер
- Добавить более агрессивное пересоздание браузера каждые N запросов
- Улучшить логику retry с пересозданием браузера
