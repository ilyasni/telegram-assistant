## Исправление

### 1. Явное преобразование ID в строку

**Файл**: `api/bot/handlers/themes_handlers.py:182, 206, 35`

**Изменения**:
1. ✅ При формировании `subscribed_theme_ids`: `{str(t["theme_id"]) for t in subscribed_themes}`
2. ✅ При сравнении в списке: `theme_id = str(theme['id'])` перед сравнением
3. ✅ При сравнении в клавиатуре: `theme_id = str(theme['id'])` перед сравнением

**Код**:
```python
# При загрузке подписок
subscribed_theme_ids = {str(t["theme_id"]) for t in subscribed_themes}

# При сравнении в списке

# При сравнении в клавиатуре

is_subscribed = theme_id in subscribed_theme_ids
```

1. **Разные типы данных** - `theme['id']` может быть UUID, а `theme_id` из подписок - строка
