**Дата**: 2026-01-13

## Проблема

**Ошибка**: Бот показывал "❌ Ошибка / Не удалось загрузить список подборок"

**Причина**: 
- Бот запрашивал `limit=1000`
- API ограничивает `limit` до 500 (`le=500`)
- FastAPI возвращал 422 Unprocessable Entity

## Решение

### Изменения в `api/bot/handlers/themes_handlers.py`

1. ✅ **Исправлен лимит**: `limit=1000` → `limit=500`
2. ✅ **Добавлена пагинация**: Если подборок > 500, делаются дополнительные запросы
3. ✅ **Улучшена обработка ошибок**: Логирование деталей ошибки

### Код

```python
# Исправлено:
themes_resp = await client.get(f"{API_BASE}/api/themes?limit=500")

# Добавлена пагинация:
if total_themes > 500:
    for offset in range(500, total_themes, 500):
        additional_resp = await client.get(
            f"{API_BASE}/api/themes?limit=500&offset={offset}",
            timeout=10
        )
        # ...
```

## Context7 Best Practices

1. ✅ **Валидация на уровне API**: Pydantic Query с ограничениями

4. ✅ **Graceful degradation**: Показываем доступные данные при частичных ошибках
