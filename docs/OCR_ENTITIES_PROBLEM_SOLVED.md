## Проблема

### Анализ реальной записи

**OCR данные**:
```json
{
  "ocr": {
    "text": "Де\nBевер\nмобилизует\nбельгийскую\nподдержку\nЕC\nпротив\nредложения\nO\nзаморозке\nактивов\nремьер\nминистр\nельгии\nзаявил\n...\nЕвропейской\nкомйссий\n...\nзамороженные\nроссийские\nаKTИBы\n...\nкредита\nКиeвy.",
    "entities": [],  ← ПРОБЛЕМА!
    "corrections": [28 исправлений],
    "text_enhanced": "..."
  }
}
```

**Ожидаемые entities** (должны быть извлечены):
1. "Европейская комиссия" (ORG)
2. "Киев" (LOC)
3. "де Бевер" (PERSON)
4. "Бельгия" (LOC)
5. "Россия" (LOC)

### Причина проблемы

**Текущий промпт** (был до исправления):
```python
"""Извлеки сущности из OCR текста. Типы:
- ORG (обязательно): банки, магазины, сервисы  ← Слишком узко!
- PRODUCT (обязательно): тип карт, эквайринг  ← Не подходит для политики
- PERSON (опционально): если явно присутствует
- LOC (опционально): города, адреса
"""
```

**Проблемы**:
1. ❌ Слишком узкая специализация (только банки/карты)
2. ❌ Требует обязательные ORG и PRODUCT (банковской тематики)
3. ❌ Не покрывает политический контекст
4. ❌ Нет примеров извлечения

---

## Решение

### Улучшенный универсальный промпт

**Файл**: `api/worker/services/ocr_enhancement_service.py` (строки 183-195)

**Улучшения**:
1. ✅ Расширенные типы сущностей с примерами
2. ✅ Поддержка разных контекстов (политика, финансы, новости)
3. ✅ Убраны обязательные требования
4. ✅ Добавлены примеры извлечения
5. ✅ Учет опечаток OCR

**Новый промпт**:
```python
"""Ты — эксперт по извлечению именованных сущностей (NER) из текста.

Извлеки все именованные сущности из OCR текста. Типы сущностей:
- ORG: организации, компании, банки, правительственные органы, международные организации, министерства, комиссии
  Примеры: "Сбербанк", "Европейская комиссия", "ЕС", "Еврактив", "ВТБ", "правительство"
- PERSON: имена людей, фамилии, политические деятели
  Примеры: "де Бевер", "Петр Иванов", "президент", "министр"
- LOC: города, страны, регионы, географические названия
  Примеры: "Киев", "Бельгия", "Россия", "Москва", "Европа"
- PRODUCT: конкретные продукты, услуги, финансовые инструменты
  Примеры: "дебетовая карта Visa", "эквайринг", "iPhone 15"

ВАЖНО:
- Извлекай сущности даже из текста с опечатками OCR
- Используй контекст для определения типа
- Если сущностей нет, верни пустой массив []
"""
```

### Дополнительные улучшения

1. **Детальное логирование**:
   - Ответ LLM перед парсингом (первые 300 символов)
   - Количество найденных и валидных entities
   - Причины фильтрации entities
   - Детальные ошибки парсинга JSON

2. **Улучшенная обработка ошибок**:
   - Логирование preview ответа при ошибке
   - Логирование типа ошибки
   - Traceback для критических ошибок
