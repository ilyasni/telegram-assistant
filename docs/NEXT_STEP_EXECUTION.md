## Шаг 2: Варианты выполнения

### Вариант A: Тестирование без перезапуска (рекомендуется сначала)

Можно протестировать новый промпт через скрипт, который инициализирует сервис напрямую:

```bash
# Тест через диагностический скрипт
python3 scripts/diagnose_ocr_entities.py
```

**Преимущества**:
- Не требует перезапуска worker
- Можно проверить работу нового промпта
- Безопасно для production

**Ограничения**:
- Worker продолжит использовать старый промпт
- Тест выполняется отдельно от worker

### Вариант B: Перезапуск worker (применение изменений)

Для применения нового промпта в production:

```bash
# Перезапуск worker
docker restart telegram-assistant-worker-1

# Проверка логов
docker logs telegram-assistant-worker-1 2>&1 | tail -50
```

**Преимущества**:
- Новый промпт применяется в production
- Все новые обработки будут использовать улучшенный промпт

**Риски**:
- Кратковременная остановка обработки
- Возможно прерывание текущих задач

## Рекомендуемый план действий

### 1. Сначала: Тестирование (без перезапуска)

```bash
# Запуск диагностики
python3 scripts/diagnose_ocr_entities.py
```

**Проверяет**:
- Находит пост с OCR текстом
- Инициализирует OCR Enhancement Service с новым кодом
- Тестирует извлечение entities
- Показывает результаты

### 2. Затем: Применение изменений (перезапуск)

Если тест успешен, перезапустить worker:

```bash
# Перезапуск worker
docker restart telegram-assistant-worker-1
```

### 3. Проверка после перезапуска

```bash
# Проверка логов
docker logs telegram-assistant-worker-1 2>&1 | grep -i "OCR Enhancement Service initialized" | tail -1

# Проверка работы entity extraction
docker logs telegram-assistant-worker-1 2>&1 | grep -i "entity extraction" | tail -10
```
