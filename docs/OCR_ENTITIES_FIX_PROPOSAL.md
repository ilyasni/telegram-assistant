# Предложение по исправлению промпта для извлечения OCR Entities

**Дата**: 2025-12-05  
**Context7**: Улучшение промпта на основе анализа реальных данных

---

## Context

Анализ реальной записи показал проблему: промпт слишком узкий и не извлекает entities из политических текстов.

**Пример**: Текст про бельгийского политика де Бевера содержит:
- "Европейская комиссия" (ORG)
- "Киев" (LOC)
- "де Бевер" (PERSON)
- "Бельгия" (LOC)

Но `entities: []` - пустой массив.

---

## Проблема текущего промпта

### Текущий промпт

```python
"""Извлеки сущности из OCR текста. Типы:
- ORG (обязательно): банки, магазины, сервисы
- PRODUCT (обязательно): тип карт, эквайринг, конкретные продукты
- PERSON (опционально): если явно присутствует (имена, должности)
- LOC (опционально): города, адреса
"""
```

**Проблемы**:
1. ❌ Слишком узкая специализация (только банки/карты)
2. ❌ Требует обязательные ORG и PRODUCT
3. ❌ Не покрывает политический контекст
4. ❌ Нет примеров извлечения

---

## Предлагаемое решение

### Улучшенный универсальный промпт

```python
"""Ты — эксперт по извлечению именованных сущностей (NER) из текста.

Извлеки все именованные сущности из OCR текста. Типы сущностей:
- ORG: организации, компании, банки, правительственные органы, международные организации, министерства, комиссии
  Примеры: "Сбербанк", "Европейская комиссия", "ЕС", "Еврактив", "ВТБ", "правительство"
- PERSON: имена людей, фамилии, политические деятели (включая должности с именами)
  Примеры: "де Бевер", "Петр Иванов", "президент", "министр", "Крис"
- LOC: города, страны, регионы, географические названия
  Примеры: "Киев", "Бельгия", "Россия", "Москва", "Европа"
- PRODUCT: конкретные продукты, услуги, финансовые инструменты (только если это конкретное название)
  Примеры: "дебетовая карта Visa", "эквайринг", "iPhone 15"

ВАЖНО:
- Извлекай сущности даже из текста с опечатками OCR (например, "Bевер" → "Бевер")
- Используй контекст для определения типа (например, "Европейская комиссия" = ORG)
- Если сущность упоминается несколько раз, используй наиболее полную форму
- Извлекай только явные именованные сущности, не общие слова
- Если сущностей нет, верни пустой массив

Верни ТОЛЬКО валидный JSON массив без дополнительного текста и комментариев:
[{"text": "название сущности", "type": "ORG|PERSON|LOC|PRODUCT", "confidence": 0.0-1.0}]"""
```

### Улучшения

1. ✅ **Универсальность**: Поддерживает разные контексты (политика, финансы, новости)
2. ✅ **Примеры**: Конкретные примеры для каждого типа
3. ✅ **Гибкость**: Нет обязательных типов
4. ✅ **OCR-aware**: Учитывает опечатки OCR
5. ✅ **Контекстное извлечение**: Использует контекст для определения типа
