## Анализ проблемы

### Проблема в промпте

**Текущий промпт** (строка 183-195):
```python
"""Извлеки сущности из OCR текста. Типы:
- ORG (обязательно): банки, магазины, сервисы
- PRODUCT (обязательно): тип карт, эквайринг, конкретные продукты
- PERSON (опционально): если явно присутствует (имена, должности)
- LOC (опционально): города, адреса
"""
```

**Проблемы**:
1. ❌ **Слишком узкая специализация**: Промпт ориентирован на банковскую тематику
2. ❌ **Обязательные типы**: Требует ORG и PRODUCT, которых может не быть в тексте
3. ❌ **Не учитывает политический контекст**: Текст про политику, а не про банки

**Результат**: LLM не находит entities, которые не соответствуют узким критериям.

---

## Решение

### Улучшенный промпт (Context7 best practice)

Промпт должен:
1. ✅ Быть универсальным для разных типов текстов
2. ✅ Не требовать обязательных типов entities
3. ✅ Поддерживать политический, финансовый, новостной контекст
4. ✅ Давать примеры извлечения

### Предлагаемый улучшенный промпт

```python
"""Ты — эксперт по извлечению именованных сущностей (NER) из текста.

Извлеки все именованные сущности из OCR текста. Типы сущностей:
- ORG: организации, компании, банки, правительственные органы, международные организации
  Примеры: "Сбербанк", "Европейская комиссия", "ЕС", "Еврактив"
- PERSON: имена людей, фамилии, должности (если содержат имя)
  Примеры: "де Бевер", "Петр Иванов", "президент Путин"
- LOC: города, страны, регионы, адреса
  Примеры: "Киев", "Бельгия", "Россия", "Москва"
- PRODUCT: конкретные продукты, услуги, финансовые инструменты
  Примеры: "дебетовая карта", "эквайринг", "iPhone"

ВАЖНО:
- Извлекай сущности даже из текста с опечатками OCR
- Используй контекст для определения типа (например, "Европейская комиссия" = ORG)
- Если сущность упоминается несколько раз, включи наиболее полную форму
- Извлекай только явные сущности, не общие слова

Верни ТОЛЬКО валидный JSON массив без дополнительного текста:
[{"text": "название сущности", "type": "ORG|PERSON|LOC|PRODUCT", "confidence": 0.0-1.0}]

Если сущностей нет, верни пустой массив: []"""
```
