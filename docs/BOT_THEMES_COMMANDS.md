# Команды бота для управления подборками

## Как подключить подборку через бота

### 1. Просмотр доступных подборок

Используйте команду:
```
/themes
```

Бот покажет список всех доступных подборок с количеством каналов в каждой. Подключенные подборки будут отмечены значком ✅.

### 2. Подключение подборки

**Способ 1: Через команду /themes**
1. Отправьте `/themes`
2. Выберите подборку из списка
3. Нажмите кнопку "✅ Подключить"

**Способ 2: Через главное меню**
1. Отправьте `/menu`
2. Нажмите кнопку "📚 Подборки"
3. Выберите подборку и нажмите "✅ Подключить"

### 3. Просмотр подключенных подборок

Используйте команду:
```
/my_themes
```

Бот покажет список всех ваших подключенных подборок с датой подключения.

### 4. Отключение подборки

1. Откройте подборку через `/themes` или `/my_themes`
2. Нажмите кнопку "❌ Отключить"
3. Подтвердите отключение

**Важно**: При отключении подборки каналы из неё будут деактивированы, но каналы, подключённые вручную, останутся активными.

## Все команды для подборок

| Команда | Описание |
|---------|----------|
| `/themes` | Показать список доступных подборок |
| `/my_themes` | Показать подключенные подборки |

## Интеграция с главным меню

В главном меню (`/menu`) добавлена кнопка "📚 Подборки", которая открывает список доступных подборок.

## Как это работает

1. **Подключение подборки**: При подключении все каналы из подборки добавляются в ваши подписки с пометкой `source='theme'`
2. **Отключение подборки**: При отключении все каналы из подборки деактивируются, но каналы с `source='manual'` остаются активными
3. **Синхронизация**: Если администратор изменит состав подборки, ваши подписки автоматически синхронизируются

## Примеры использования

### Пример 1: Подключение подборки "AI & ML"
```
Пользователь: /themes
Бот: [Показывает список подборок]
Пользователь: [Нажимает на "AI & ML"]
Бот: [Показывает информацию о подборке]
Пользователь: [Нажимает "✅ Подключить"]
Бот: ✅ Подборка подключена! Добавлено каналов: 15
```

### Пример 2: Просмотр подключенных подборок
```
Пользователь: /my_themes
Бот: 📚 Мои подборки

✅ AI & ML
   Подключено: 2026-01-13

✅ Crypto & Blockchain
   Подключено: 2026-01-12
```

## Технические детали

- API endpoints используются без токена авторизации (используется `telegram_id`)
- Все операции выполняются через HTTP запросы к основному API
- Callback-кнопки используются для интерактивного управления
- Ошибки обрабатываются с понятными сообщениями для пользователя
