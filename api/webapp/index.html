🔐 Авторизация

Отсканируйте QR-код в Telegram для входа

Инициализация...
Как войти:
1. Откройте Telegram на другом устройстве
2. Перейдите в Настройки → Устройства
3. Нажмите "Привязать устройство"
4. Отсканируйте QR-код

🔐 Требуется пароль 2FA

Введите пароль двухфакторной аутентификации для завершения входа
