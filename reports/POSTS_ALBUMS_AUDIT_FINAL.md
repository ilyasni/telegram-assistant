## Критическая проблема: Посты не сохраняются

### Проблема

После создания подписки в `atomic_db_saver.py` переменная `subscription_row` не обновлялась, и посты не сохранялись:

```python
# Строки 251-262: Создание подписки
await db_session.execute(...)  # Создает подписку

# Строки 267-274: Проверка subscription_row
if not subscription_row:  # ❌ Все еще None!
    return False, "user_not_subscribed", 0  # Посты не сохраняются!
```

**Влияние**: 
- Посты пропускались даже после создания подписки
- Это объясняет огромные пропуски постов в каналах

---

## Исправление (Context7)

### Добавлена перепроверка подписки

**Файл**: `telethon-ingest/services/atomic_db_saver.py`

**Изменение**: После создания подписки добавлена перепроверка:

```python
# После создания подписки
check_subscription_after_create = await db_session.execute(
    text("""
        SELECT user_id, is_active FROM user_channel 
        WHERE user_id = :user_id AND channel_id = :channel_id
        LIMIT 1
    """),
    {"user_id": user_id_uuid, "channel_id": channel_id_uuid}
)
subscription_row = check_subscription_after_create.fetchone()
```

**Результат**: Теперь `subscription_row` обновляется после создания подписки, и посты сохраняются.
