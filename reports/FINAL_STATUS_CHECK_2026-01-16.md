**1. Увеличено `max_check_before_stop`:**
- Было: `20` сообщений
- Стало: `200` сообщений

**2. Увеличен `limit` для incremental:**
- Было: `batch_size * 100`
- Стало: `batch_size * 500`

**3. ✅ ДОБАВЛЕНО использование `offset_id`:**
- Получаем `last_message_id` из БД для каждого канала
- Используем `offset_id=last_message_id` при запросе к Telegram API
- Telegram API возвращает только сообщения с `message_id > last_message_id`

### Изменения в коде

**`telethon_retry.py`:**
- Добавлен параметр `offset_id: Optional[int]`
- Добавлено `iter_params["offset_id"] = offset_id`

**`channel_parser.py`:**
- Добавлено получение `last_message_id` из БД для incremental режима
- Добавлено использование `offset_id` при запросе сообщений
- Передача `channel_id` в `_get_message_batches` для получения `last_message_id`
